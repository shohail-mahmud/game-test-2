# Game Test 2

Vite + React + Three.js pirate sea exploration game.

## Features

- Textured Kenney Pirate Kit player ship and world props
- Coin economy and Shipyard boat shop
- Kenney Watercraft Kit unlockable boats from 500 to 25,000 coins
- Local save for gold, owned boats, and equipped boat
- Enhanced ocean waves/foam with Ocean Wave - w/Maya attribution
- About page with 3D credits and developer info

## Local run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel settings

- Framework preset: Vite
- Build command: npm run build
- Output directory: dist
- Install command: npm install
- Root directory: leave empty
